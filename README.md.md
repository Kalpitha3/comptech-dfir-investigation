# Digital Forensic Investigation of the CompTech Breach

**Timeframe:** April – May 2026
**Domain:** Digital Forensics & Incident Response (DFIR)

## Overview
A simulated breach investigation into a compromised system ("CompTech"), focused on
reconstructing what happened from available forensic artifacts — memory, disk, and
network traffic — and producing a formal incident report a security team could act on.

## Tools & Technologies
- **Volatility** — memory forensics and process/artifact extraction
- **Autopsy** — disk forensics and file system analysis
- **Wireshark** — network traffic capture and analysis

## What I Did
- Investigated memory, disk, and network traffic to identify indicators of compromise (IoCs).
- Reconstructed the attacker's activity end-to-end, from initial access through to impact.
- Extracted and correlated system artifacts across the three evidence sources to build a
  consistent timeline of the incident.
- Documented findings in a detailed incident report following standard DFIR methodology
  (identification, preservation, analysis, and reporting).
